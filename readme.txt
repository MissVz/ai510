## 📘 Course Overview

**AI510 - Artificial Intelligence in Cloud Computing** explores AI workloads, cloud-based tools, and machine learning services across popular cloud platforms. It emphasizes hands-on experience with MLOps, AutoML, CI/CD, and deploying AI models on AWS, Azure, and GCP.

_“Design and implement an AI solution utilizing cloud enterprise AI services.”_ 

---

## 🎯 Repository Purpose

This repository contains **Hands-On Skills (HOS)** and **Programming Exercises (PE)** for AI510. Each assignment is designed to demonstrate practical knowledge of:

- Cloud-based AI workflows
- No-code and low-code ML tools
- REST APIs and SDKs for AI services
- MLOps pipelines and monitoring
- AutoML implementations
- Cloud platform integration (AWS, Azure, GCP)

---
